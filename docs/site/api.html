L.not(pred) ⇒ function

Returns a function that returns the logical negation of a predicate.

The returned function calls pred with its received arguments and returns the opposite of Lemonad truthiness for the result.

Kind: static method of L
Returns: function - A predicate that returns true when pred returns a falsey value, and false otherwise.

Param Type Description
pred function Predicate function to negate.

Example 

L.not(L.isEven)(3)
//=> true

Example 

var isNotString = L.not(L.isString);

isNotString(42)
//=> true

L.map(fun, [coll]) ⇒ Array | function

Applies a function to each element of a collection.

May be called with both arguments:

L.map(L.inc, [1, 2, 3])
//=> [2, 3, 4]

Or partially applied:

L.map(L.inc)([1, 2, 3])
//=> [2, 3, 4]

Kind: static method of L
Returns: Array | function - An array when coll is supplied, otherwise a function expecting coll.

Param Type Description
fun function Function applied to each element.
[coll] Array Optional collection to map over.
